# Vanish: Disney Lorcana keyword

Source: https://www.readysetink.com/keywords/vanish/

If an opponent chooses this character as part of an action's effect, it gets banished afterwards. A built-in risk for anyone who targets it. Official rule 8.14. 7 cards.
